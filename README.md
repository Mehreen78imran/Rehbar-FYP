# Rehbar FYP

**Rehbar — An AI-Based Hands-Free Voice Navigation Assistant for Visually Impaired People on the University Campus**

## Overview
Rehbar is a proposed Android-based assistive navigation prototype that combines camera-based object detection, campus waypoint navigation and Urdu/English voice guidance.

## Planned Features
- Camera-based obstacle detection
- Approximate obstacle direction
- Campus route guidance
- Voice commands and spoken instructions
- Optional vibration alerts

## Proposed Technology Stack
- Python and YOLO
- OpenCV
- Google Colab for AI experiments
- Android application framework to be finalized
- Campus waypoint graph
- Git and GitHub

## Project Status
Initial implementation and feasibility testing are in progress.

## Safety
This research prototype is not a replacement for a white cane or other established mobility aids. Testing requires appropriate supervision and safety precautions.
